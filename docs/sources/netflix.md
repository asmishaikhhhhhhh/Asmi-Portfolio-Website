## 2. Structured extraction (only what the images show)

- **One-liner**: NOT STATED in the images. The only goal statement is slide 15: "To optimize the process of selecting content and minimize search time for individuals". The portfolio line comes from the brief.
- **Context**:
  - A redesign of the Netflix **mobile web** experience (netflix.com/browse viewed in a phone browser, slides 03, 04, 32, 33).
  - Target audience claims (01): broad range; more female than male users; mainly younger adults. No source is given.
  - Stakeholder map (01).
  - Personas are all based in Mumbai, Maharashtra (17 to 19).
  - The test lab photos carry an "SVKM's NMIMS School of Design" watermark (24). That suggests an academic setting, but the slides never say it is a course project.
- **Problems with the existing site** (interface analysis, 03 and 04):
  1. No navigation tab.
  2. The burger menu is very cluttered.
  3. The site prompts users to join the app instead of offering app features.
  4. The category name is not highlighted on category pages.
  - No formal heuristic framework (such as Nielsen's) is named.
- **Proposed fixes** (03 and 04):
  - Add a navigation panel under the header.
  - Move menu categories into that tab.
  - Bring app features into the website ("can also cut down on app-managing costs").
  - Make the category name bold and big.
- **Research and testing methods**:
  - Interface analysis.
  - Personas (3).
  - Paper prototype, then mid-fidelity, then hi-fi.
  - Moderated usability testing in a lab with user/moderator and observer rooms (24).
  - Metrics evaluation (time, error rate, assistance), think-aloud protocol, observational analysis (22).
  - Two tasks (20).
  - Task 2 framed as "Prospective Test: A/B testing", old vs new (32, 38).
  - Participants: 8 users are shown in the Task 2 chart (38). The total participant count for Task 1 is NOT STATED. Participant demographics and recruitment are NOT STATED.
- **Key stats** (Task 2, old vs new):
  - Average time 34s vs 40s. The new design was slower. The slide attributes this to more filter options and users being "comfortable spending time" (34).
  - Success rate 50% vs 80% (35).
  - Confusion 70% vs 40% (36).
  - Per-user times as in the table under 38. User 3: 1:46 vs 1:20. User 5: 12s vs 44s.
  - "2-3 users did no find the filter button and used the search button" on the old site (35, 36).
  - Ratings: existing 2/5, new 4/5 stars (41). The method is NOT STATED.
  - Ease scale: old 4 dots, new about 2.5 dots on an EASY to DIFFICULT scale (33). Not explained.
  - Task 1: "Only 2 users mentioned it" (27).
  - How "success rate" and "confusion" were measured is NOT STATED.
- **Insights**:
  - Recommend Me was noticed only when users scrolled, because it is a fixed floating button. Users rarely recalled it, and one user read it as shuffle play (27).
  - The "+" add-to-list button sometimes blends into posters (30).
  - Users struggled to close the filter options (39).
  - The filter icon was too small and dark (39).
  - More specific filter options meant more time (39).
  - User emotions improved from sad/neutral (old) to neutral/happy (new) (37).
- **Redesign decisions (before to after)**:
  - Burger menu with a long category list → persistent pill tabs "TV shows / Movies / My List" under the header (03 → 13).
  - Search box only → search bar "Search by Movies, TV shows or people" plus a filter (funnel) icon. Filter facets (from paper and mid-fi): Category, Language, Genre, Region, Maturity/Rating, Year Released (08, 10).
  - Horizontal category rows of landscape thumbnails → a 3-column poster grid with "+" add-to-My-List on each poster (03 → 13).
  - New floating "Recommend me" button (13, 26).
  - Home page sections: Continue Watching, My List, Trending Now, Top 10 on Netflix, New Releases, Popular on Netflix, Netflix Originals, Top 10 Picks for You (12, 08).
  - Title-detail page with cast, season episodes and "More like this" (12).
  - Whether the testing recommendations (28, 31, 40) were implemented afterwards is NOT STATED. No post-test iteration screens are shown.
- **Features**: nav tabs, search with filter, Recommend me, add to My List, Continue Watching with progress, Top 10, title page with cast and more-like-this.
- **Design system** (06):
  - Colour palette: 3 reds, white/greys, blacks. No hex codes.
  - Netflix Sans Regular/Medium/Bold. Sizes: H1 36px, H2 32px, H3 24px, Body 18px, plus smaller sizes.
  - Blocks (white, transparent, gray, red and red-transparent backgrounds).
  - Icon library in 14 categories.
  - The section is titled "MATERIAL UI".
- **Outcomes**: success rate up from 50% to 80%, confusion down from 70% to 40%, rating up from 2 to 4 stars, average time up from 34s to 40s. No business or real-world outcome.
- **Learnings / reflection**: NOT STATED. The deck ends with "THANKYOU".
- **Duration**: NOT STATED.
- **Team and division of work**: no names appear anywhere in the images. Asmi's specific contribution is NOT STATED, and so is Deep Udeshi's. The slides use "we" and "our redesign" (24, 34).
- **Tools**: NOT STATED in the images (the brief lists Photoshop, Illustrator, Figma).
- **Year**: NOT STATED in the images (Aug 2025 is the Behance publish date per the brief). The screenshots include 2023 titles (Afwaah, Tu Jhoothi Main Makkaar, Extraction 2), and the paper "Time Released" list starts at 2023. That hints at the work date, but the slides do not state it.
